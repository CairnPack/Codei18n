# 规范增量：文档注释结构化翻译

## 新增需求

### 需求：受保护片段不参与翻译

文档注释中的代码引用、类型、参数名、标签与代码块必须替换为占位符后再交给翻译器，翻译后原样还原。

#### 场景：Javadoc
- **当** 翻译 `* Returns the {@code sum} ... @param a the first {@link Number}`
- **那么** 发给翻译器的文本不含 `{@code`、`@param a`、`/**`，译文中这些片段与外框原样保留

### 需求：占位符校验

还原前必须校验占位符一个不少、一个不多、顺序不变；失败重试 1 次，仍失败则标记为失败，不写入译文。

#### 场景：译文丢失占位符
- **当** 翻译器两次都丢掉占位符
- **那么** 该条记为失败，mappings.json 中不出现该条的译文
