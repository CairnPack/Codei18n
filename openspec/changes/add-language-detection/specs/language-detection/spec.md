# 规范增量：多语种识别

## 新增需求

### 需求：识别注释原语言

map update 必须为每条注释识别原语言（规范化 BCP 47），写入 index.json；判断不了时为 unknown，不强行归类。

#### 场景：日语注释
- **当** 源语言为 en、本地语言为 zh-CN，源码中有日语注释
- **那么** index.json 中 lang 为 ja，原文存放在 mappings 的 ja 键下，翻译补全 zh-CN 与 en

#### 场景：候选集合之外的语言
- **当** 候选集合为 en、zh-Hans、ja，源码中有德语注释
- **那么** lang 为 unknown，原文按旧规则存放在源语言键下

### 需求：短文本启发式

剩余文本过短时按字符集判断；拉丁字母短文本判为 unknown。

#### 场景：短注释
- **当** 注释为 "// TODO fix"
- **那么** lang 为 unknown
