# 规范增量：令牌存储

## 新增需求

### 需求：令牌只存系统凭据库

令牌必须保存在系统凭据库，格式为 generic credential、TargetName `codei18n/<account>`、UserName `<account>`；配置文件只存引用名。

#### 场景：桌面端保存后 CLI 直接可用
- **当** 通过 core API 保存 profile 的全局令牌
- **那么** 不设置任何环境变量时，`codei18n translate` 与 pre-commit hook 都能使用该令牌

### 需求：读取优先级与来源层

系统应按 环境变量 > 项目级覆盖令牌 > 所选 profile 全局令牌 > 旧版明文字段 的顺序读取，并能报告生效来源层与末 4 位。

#### 场景：查看状态
- **当** 运行 `codei18n auth status`
- **那么** 显示项目 / 全局令牌是否已保存、末 4 位与生效来源，不显示明文

### 需求：旧版明文迁移

读到配置文件中的明文令牌时照常使用并警告，并提供迁移命令把明文迁入凭据库、从文件删除该字段。

#### 场景：迁移
- **当** 运行 `codei18n auth migrate`
- **那么** 令牌写入凭据库，配置文件中不再包含明文，其余字段保持不变

### 需求：防泄漏

令牌不得出现在日志、错误信息、进度事件、失败记录与测试快照中。

#### 场景：后端回显令牌
- **当** 翻译后端的错误信息中包含 Authorization 头与 key 片段
- **那么** 返回结果、失败记录文件、日志与进度事件中都不包含令牌或其片段
